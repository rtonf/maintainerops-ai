# v0.1.12 Model-Backed Eval Readiness

MaintainerOps AI `v0.1.12` expands model-backed eval readiness and records the first passing 10-case live eval run.

## Highlights

- Added a dedicated model-backed eval case file with 10 cases.
- Added `smoke`, `expanded`, and `all` model eval suites.
- Added targeted `--case` execution.
- Added `--cases-file` and `--summary-json` controls.
- Added API-free case listing with `npm run eval:model:list`.
- Added stricter eval checks for recommended actions, forbidden recommended actions, minimum risk, and maximum risk.
- Improved normalization for dependency updates, license metadata issues, and direct security-boundary findings.
- Added methodology and result docs for manual model-backed evals.

## Guardrails

- Live model-backed evals remain manual-only.
- Live evals are not part of CI.
- Every live eval run must use explicit budget and case-count controls.
- MaintainerOps AI still does not auto-merge, auto-close, auto-label, publish releases, or scan unauthorized repositories.
