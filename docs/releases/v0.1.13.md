# v0.1.13 No-Key Demo Path

MaintainerOps AI `v0.1.13` focuses on external maintainer feedback. It adds a no-key CLI demo command so reviewers can see a real review packet without cloning fixtures, setting an API key, or preparing a repository event.

## Changes

- Added `maintainerops demo`.
- Demo mode always uses deterministic offline analysis.
- Demo mode supports `--format markdown` and `--format json`.
- Updated npm and Marketplace tester instructions to use the no-key packet path.
- Confirmed the public GitHub Marketplace listing displays `v0.1.12` before preparing this release.
- Added an API-free security diff review for the demo path.

## Tester Path

```bash
npm exec --yes --package maintainerops-ai@latest -- maintainerops demo
```

Fallback help check:

```bash
npm exec --yes --package maintainerops-ai@latest -- maintainerops --help
```

## Safety

- No OpenAI API key is required.
- No GitHub token is required.
- No repository is scanned.
- No issue, label, comment, release, or pull request is modified.
